# README

This repository provides representative data and code support for the manuscript **"Agri-PIDNet-S: lightweight semantic segmentation for field-structure and obstacle perception in seedling-stage cotton fields."** It contains a representative minimal dataset with RGB images and pixel-wise labels for background, crop row, furrow, and obstacle classes, together with `train.py` and `infer_evaluate.py` as concise entry scripts for model training, inference, and evaluation. For more detailed information or access to the complete dataset, please contact the first author, Yanlin Xin, at [320243431@xjau.edu.cn](mailto:320243431@xjau.edu.cn).
